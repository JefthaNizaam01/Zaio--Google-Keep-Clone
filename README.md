# Google Keep

A small Google Keep-style notes app made with HTML, CSS and JavaScript.

## How to run

Open `index.html` in a web browser. No extra packages or setup are needed.

## Features

- Add a note with a title, text, or both.
- View all notes and move notes to or from the archive.
- Search notes by title or text.
- Switch between grid and list note layouts.
- Notes are saved in the browser's local storage.
